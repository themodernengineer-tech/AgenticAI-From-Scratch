# AgenticAI-From-Scratch


A beginner-friendly, hands-on journey into AI agents and Agentic AI. This repository documents daily lessons, experiments, and projects built step by step with Python and Gemini.

The roadmap combines practical agent engineering with preparation for the NVIDIA Certified Professional: Agentic AI (NCP-AAI) exam.

## Learning Path

1. Agent foundations and the first model-powered application
2. Agent loops, tools, workflows, state, and memory
3. Planning, evaluation, and multi-agent systems
4. RAG, Agentic RAG, and MCP
5. Customization, safety, and human oversight
6. NVIDIA agent tools, deployment, monitoring, and production engineering

## Projects

| Project | What it demonstrates | Status |
|---|---|---|
| First Gemini API call | Python project setup and a model request using Google’s Gemini SDK | In progress |
| First tool-using agent | An agent that chooses and uses a limited tool | Planned |
| Deep research assistant | Research, evidence gathering, and synthesis | Planned |
| Agentic RAG assistant | Retrieval, citations, and grounded answers | Planned |
| Safe autonomous agent | Permissions, isolation, and human oversight | Planned |
